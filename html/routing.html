SESS.DN42 Routing Policy

SessNetwork (AS4242422466) uses a custom routing method designed for the dn42 internet. We call it Poisoned Potato Routing.

Routing Preference

We use bgp_local_pref to determine the preferred route and bgp_med to describe link quality.

eBGP Import

The base bgp_local_pref is 200. The following adjustments are applied:

AS-PATH length < 2+100
AS-PATH length < 3+40
AS-PATH length < 4+20
ROA status is unknown-90
Same region+60
Same country+40

Routes with an invalid ROA status are rejected.

iBGP Import

The base bgp_local_pref is 180, with the following adjustments:

AS-PATH length < 2+100
AS-PATH length < 3+40
AS-PATH length < 4+20
ROA status is unknown-90
Same region+40
Same country+20

The iBGP import filter sets the base bgp_med to 500.

MED Calculation

For DN42 eBGP routes, MED is recalculated using link characteristics. The calculation is:

bgp_med = (latency - DN42_LATENCY_0) * 20 + (DN42_BANDWIDTH_10T - bandwidth) * 10 + (DN42_ENCRYPT_SAFE_PFS_PQC_PFS - encryption) * 30 + (topology - DN42_TOPOLOGY_PHYS) * 30 + (packetloss - DN42_PKTLOSS_0) * 80;

Lower MED values are preferred. Better latency, bandwidth, encryption, topology, and packet loss characteristics result in a lower metric.

The link characteristics are represented by dn42 standard communities. The filter normalizes each characteristic to a single community before calculating MED.

Import Policy

Prefix Validation

dn42 imports are restricted to the following prefix ranges:

IPv4172.20.0.0/14dn42
IPv4172.20.0.0/24, 172.21.0.0/24, 172.22.0.0/24, 172.23.0.0/24dn42 Anycast
IPv4172.31.0.0/16+ChaosVPN
IPv410.100.0.0/14+ChaosVPN
IPv410.127.0.0/16+neonetwork
IPv410.0.0.0/8{15,24}Freifunk.net
IPv6fd00::/8{44,64}dn42

Prefixes outside these ranges, prefixes in the configured rejection sets, and unsupported address families are rejected.

AS-PATH Limits

PeerMaximum 3 AS-PATH entries
CustomerMaximum 4 AS-PATH entries
Other rolesMaximum 32 AS-PATH entries

The general maximum AS-PATH length is 32. The peer and customer limits are stricter.

Export Policy

eBGP Export

The dn42 eBGP export filter applies the following rules:

  • Reject routes carrying NO_EXPORT, NO_EXPORT_SUBCONFED, or NO_ADVERTISE.
  • Reject routes outside the configured dn42 prefix ranges.
  • Reject routes with an invalid ROA status according to the export ROA table.
  • Apply AS-PATH prepending and export-control communities.
  • Apply neighbor-role propagation restrictions.
  • Only export BGP routes and explicitly handled static aggregate routes.

Route Propagation by Neighbor Role

Routes learned from different neighbor roles have different export permissions:

PeerCustomer routes only
IXCustomer routes only
ProviderCustomer and partner routes
CustomerCustomer, partner, peer, and IX routes
PartnerAS-PATH length limited to 32

These restrictions are based on the SESS_LEARN_ROLE metadata attached during import.

iBGP Export

The iBGP export filter:

  • Rejects routes carrying NO_ADVERTISE.
  • Rejects routes with an invalid export ROA status.
  • Rejects a route if its BGP next hop matches the target neighbor address.
  • Supports AS-PATH prepending and export-control communities by role, region, country, and neighbor.
  • Exports static routes and BGP routes.

Static routes receive the local dn42 region and country communities before being exported.
