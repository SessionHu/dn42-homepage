SESS.DN42 Routing Policy

SessNetwork (AS4242422466) uses a custom routing method designed for the dn42 internet. We call it Poisoned Potato Routing.

Routing Preference

We use bgp_local_pref to determine the preferred route and bgp_med to describe link quality.

eBGP Import

The base bgp_local_pref is 200. Routes with an invalid ROA status are rejected.

AS-PATH length < 2+100
AS-PATH length < 3+40
AS-PATH length < 4+20
ROA Unknown-90
Same region+60
Same country+40

iBGP Import

The base bgp_local_pref is 180.

MED Calculation

The eBGP import filter calculate MED with (latency - DN42_LATENCY_0) * 20 + (DN42_BANDWIDTH_10T - bandwidth) * 10 + (DN42_ENCRYPT_SAFE_PFS_PQC_PFS - encryption) * 30 + (topology - DN42_TOPOLOGY_PHYS) * 30 + (packetloss - DN42_PKTLOSS_0) * 80;

The iBGP import filter sets the base bgp_med to 500.
